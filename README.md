# Дано — конспекты и практика

[Открыть сайт](https://1dambek1.github.io/dano_conspects_group/)

Разделы на русском языке: Python, pandas, вероятность, статистика, практикум и пять самостоятельных кейсов ДАНО. Сайт сразу открывает конспект Python. Отдельной главной страницы и footer нет.

## Содержание

- **Python:** переменные и типы, условия, циклы, списки, функции.
- **pandas:** устройство DataFrame и Series, чтение CSV, маски и фильтры, пропуски, groupby, agg, transform, сводные таблицы, соединение, даты и строки, графики и справочник основных методов.
- **Вероятность:** исходы, события, сочетания, условная вероятность, полная вероятность и формула Байеса.
- **Статистика:** среднее, дисперсия, стандартное отклонение и SE; распределения, ЗБЧ, ЦПТ и доверительные интервалы; t-тесты, ANOVA и χ²; линейная регрессия от простой прямой до статистики весов, вложенных моделей, диагностики, переобучения и парадокса Симпсона.
- **Кейсы ДАНО:** пять работ с CSV по вероятности, регрессии, размещению станций, географии цен и парадоксу Симпсона. Все новые материалы находятся в [students](students/README.md).
- **Практикум:** 11 тематических блоков с микрозадачами, большими работами и CSV по Python, pandas, графикам, вероятности, статистическим тестам, NumPy, sklearn и регрессии. Данные и структура описаны в [students/practice](students/practice/README.md).

После каждой темы идут тренировочные задачи с подсказками и разборами. Пять больших кейсов опубликованы без готовых ответов. Страница «Практика» собирает задания в одном месте. Есть интерактивная галерея графиков, модели ЗБЧ и ЦПТ, графики распределений и регрессии, таблица pandas, визуализация цикла и калькулятор Байеса. [Учебный CSV](student_scores_80.csv) содержит 80 строк.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Сборка не требуется. Формулы отображаются через MathJax CDN и требуют подключения к интернету. Для выполнения примеров Python нужны `pandas`, `scipy`, `statsmodels` и `scikit-learn`.
