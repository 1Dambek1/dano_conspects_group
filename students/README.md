# Материалы для учеников

Этот каталог содержит новые конспекты для сайта и пять самостоятельных кейсов по мотивам формата ДАНО. Данные кейсов вымышлены и воспроизводятся командой python tools/generate_datasets.py. Ответы в материалах не опубликованы.

Отдельный [практикум](practice/README.md) добавляет 12 тематических блоков с короткими упражнениями и большими работами. Четыре CSV о доставке еды и три CSV для сборки кейса из двух волн опроса лежат в `practice/data/`; остальные блоки используют данные кейсов ниже.

## Порядок работы

1. На [сайте](https://1dambek1.github.io/dano_conspects_group/) пройдите разделы **pandas** и **Статистика**, особенно groupby, agg, transform, графики и блоки регрессии от базы до продвинутых тем.
   В разделе pandas есть отдельная серия **«Кейсы ДАНО: как читать код pandas»**: пять коротких примеров на CSV этих заданий с объяснением каждой строки и самостоятельным продолжением.
   Для начала есть короткие упражнения по Python (переменные, списки, циклы, функции) и pandas (таблица, фильтры, новые столбцы, `pd.concat` и `axis`).
2. Для каждого кейса прочитайте условие, скачайте CSV и сохраните код с короткими письменными выводами. Графики должны иметь подписи осей и название.
3. Используйте один и тот же набор строк при сравнении вложенных моделей. Для оценки прогноза отделяйте тестовую выборку до обучения и стандартизации.
4. Сдавайте код или ноутбук, графики и ответы на вопросы своими словами. Показать одну цифру без объяснения недостаточно.

## Словарь колонок

- **Кейс 1:** stage — bus/metro; wait_min — ожидание; probability — вероятность. В журнале rush_hour и rain равны 0/1, extra_delay_min — дополнительная задержка, late_38min — опоздание при сроке 38 минут.
- **Кейс 2:** wayfinding_score — качество навигации, landmarks_n — число достопримечательностей, night_cost — стоимость поездки, route_length_km — длина, route_rating — рейтинг. district — район. Часть значений night_cost отсутствует.
- **Кейс 3:** x,y — координаты жителя, district — район, willingness_A — индивидуальный множитель готовности платить.
- **Кейс 4:** city_id — ключ города; home_id — ключ квартиры; area_sqm — площадь; price_thousand — цена в тысячах условных единиц; origin_id, destination_id, travel_min — пары городов и время поездки.
- **Кейс 5:** id — номер наблюдения от 1 до 100; group — группа A (строки 1–50) или B (51–100); X и Y — числовые показатели для трёх регрессий.

Для Python-практики понадобятся pandas, numpy, matplotlib, scipy, statsmodels и scikit-learn. Например:

    python -m pip install pandas numpy matplotlib scipy statsmodels scikit-learn
