# Практикум

[Открыть практикум на сайте](https://1dambek1.github.io/dano_conspects_group/#trainer)

Одиннадцать блоков содержат короткие упражнения и большие самостоятельные работы. Ответы не опубликованы. Галочки у микрозадач сохраняются в браузере, где они были поставлены.

## Данные доставки

| CSV | Строки | Смысл строки |
| --- | ---: | --- |
| [customers.csv](data/customers.csv) | 240 | клиент |
| [restaurants.csv](data/restaurants.csv) | 32 | ресторан |
| [orders.csv](data/orders.csv) | 1400 | заказ |
| [order_items.csv](data/order_items.csv) | 3535 | позиция заказа |

Связи: `orders.customer_id → customers.customer_id`, `orders.restaurant_id → restaurants.restaurant_id`, `order_items.order_id → orders.order_id`. Позиции отменённых заказов есть в файле, но их `paid_rub` равен нулю. После соединения заказа с позициями одна сумма `paid_rub` повторяется на нескольких строках. Пропуски возраста, оценки и времени доставки задуманы как часть практики.

Значения синтетические. Данные по ожиданию транспорта, маршрутам, квартирам и парадоксу Симпсона берутся из [общего набора студентов](../README.md). В каждом блоке сайта показаны только нужные для него ссылки.

## Как работать

Скачайте данные нужного блока, решите микрозадачи, затем большую работу. Для задач с графиками подпишите оси и единицы измерения. Для статистических тестов сначала запишите нулевую гипотезу и размер каждой группы. Код и выводы можно присылать на проверку по одной задаче.
